What a review finding looks like

This is an example of the format, not a client finding. The reasoning comes from my article on load testing Event Hubs processing.

finding
Load test passes while consumers fall behind
observed
The test reports response times from the producer side. An Event Hubs acknowledgment only confirms that the broker accepted the event, not that it was processed.
impact
A backlog can build up without showing in the results, so a passing test says little about how much load the consumers can handle.
recommendation
Track enqueue-to-processed lead time as a pre-aggregated custom metric with GetMetric, and read it alongside the load test results.
tradeoff
The consumer code gains instrumentation, and you have one more custom metric to maintain.
